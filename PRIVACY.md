# Privacy Policy — Mandala Explorer

Effective 3 November 2026.

Mandala Explorer collects nothing. It has no accounts, no telemetry, no
analytics or advertising, and does not send usage data to a server. Accessing
network folders you choose, or invoking Windows Shell commands and installed
extensions, may involve network services provided by Windows or other apps.

## What it reads

The folder you point it at, and the pictures and video in it. It reads those
files to draw thumbnails and to play video in the grid. When you request a
file operation, it uses the Windows Shell to copy, move, rename or otherwise
manage the selected files. Copy and cut place file references on the Windows
clipboard. To preview an image inside a ZIP, it extracts
that image to a local temporary file, which is removed after decoding.

## What it stores, on your own computer

| | |
| --- | --- |
| Thumbnail cache | Reduced-size images made from your files, so a folder you have visited opens quickly. Capped at 2 GB; the oldest entries are discarded as it fills. |
| Settings | Directory paths and their view preferences (thumbnail size, playback count, sort order, autoplay, sound and filename visibility), bookmarked folder paths, and the window's size and position. |
| Temporary ZIP images | Only images needed for previews, in the Windows temporary directory. Removed after decoding; limited to 256 MiB per image and 512 MiB in total. An interrupted process may leave temporary files for Windows or the user to clean up. |

The cache and settings live in the application data folders Windows provides. For a copy
installed from the Microsoft Store those are inside the app's own package
storage, and uninstalling the app removes them. Temporary ZIP images use the
temporary directory described above.

## What it never does

- Send your files, filenames, folder paths, or thumbnails anywhere
- Operate its own update, licensing or analytics network service
- Identify you, or build a profile of what you look at
- Show advertising, or share anything with a third party

## Children

The app is not directed at children and collects no information from anyone,
of any age.

## Changes

If this policy ever changes, the revised version will be published at this
address with a new effective date. A policy change alone cannot alter the
behaviour of a copy already installed.

# プライバシー ポリシー — Mandala Explorer

2026年11月3日 発効。

Mandala Explorer は情報を一切収集しません。アカウント、利用統計、アクセス解析、
広告のいずれもなく、利用情報をサーバーに送信しません。お客様が指定したネットワーク
フォルダーへのアクセスや、Windowsの標準メニュー・インストール済みの拡張機能の実行では、
Windowsや他のアプリが提供するネットワークサービスが使われる場合があります。

## 読み取るもの

お客様が指定したフォルダーと、その中の画像および動画です。サムネイルの生成と、
グリッド内での動画再生のために読み取ります。お客様がファイル操作を指示した場合は、
Windowsの機能を使って選択されたファイルのコピー、移動、名前変更などを行います。
コピー・切り取り時はファイルの参照をWindowsのクリップボードに格納します。
ZIP内の画像をプレビューする際は、その画像をローカルの一時ファイルに
展開し、デコード後に削除します。

## お客様のコンピューター内に保存するもの

| | |
| --- | --- |
| サムネイル キャッシュ | 一度見たフォルダーをすぐ開けるようにするため、ファイルから生成した縮小画像を保存します。上限は 2 GB で、超えると古いものから破棄します。 |
| 設定 | フォルダーのパスと表示設定（サムネイルのサイズ、同時再生数、並べ替え順、自動再生、音声、ファイル名の表示有無）、ブックマークのパス、ウィンドウのサイズと位置。 |
| ZIP画像の一時ファイル | プレビューに必要な画像だけをWindowsの一時フォルダーに展開し、デコード後に削除します。上限は1画像256 MiB、合計512 MiBです。プロセスが中断された場合は残ることがあり、Windowsまたはお客様による削除が必要になる場合があります。 |

キャッシュと設定は Windows が提供するアプリケーション データ フォルダーに保存されます。
Microsoft Store からインストールした場合、その保存先はアプリ自身のパッケージ
ストレージ内であり、アンインストールすると削除されます。ZIP画像の一時ファイルは
上記の一時フォルダーに保存されます。

## 行わないこと

- ファイル、ファイル名、フォルダーのパス、サムネイルの外部への送信
- 独自の更新確認・ライセンス認証・利用状況分析のためのネットワークサービスの運用
- お客様の識別、および閲覧内容のプロファイル作成
- 広告の表示、および第三者への情報提供

## お子様について

本アプリは子供を対象としたものではなく、年齢を問わずいかなる情報も収集しません。

## 変更について

本ポリシーを変更する場合は、新しい発効日を付して同じアドレスに掲載します。本アプ
リのポリシー変更だけで、既にインストールされたアプリの動作が変わることはありません。
